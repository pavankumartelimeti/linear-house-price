# Data Dictionary

`data/raw/house_prices_raw.csv` — 3,000 simulated home sales in a fictitious
city, generated by `src/data/make_dataset.py` (seed=42, fully reproducible).

**Why simulated?** Controlling the data-generating process means we know
the *true* coefficients — including which features have exactly zero true
effect on price. That lets us check Lasso's feature selection and Ridge's
stability claims against ground truth, which a real, unlabeled dataset can't
offer. See the README for the full rationale.

## Known-zero-effect columns (used to sanity-check feature selection)

`noise_1`, `noise_2`, `noise_3` were generated independently of price by
construction. `year_built` and `year_remod` were *also* never given a
coefficient in the true price formula (see `make_dataset.py`) — they only
enter the model indirectly, once feature engineering derives `age_of_house`
from `year_built`. All five are legitimate targets for Lasso to zero out;
see the README for which ones it actually does.

## Deliberately introduced multicollinearity

Not present in this raw file — introduced during feature engineering
(`src/features/build_features.py`), which derives `age_of_house` (from
`year_built`) and `total_sf` (from `gr_liv_area` + `total_bsmt_sf`). See the
README's VIF analysis.
